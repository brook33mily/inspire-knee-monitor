# INSPIRE Knee Monitor

Brooke Karl's INSPIRE research project.

## Goal
Develop a two-IMU wearable prototype to measure knee motion and
investigate feedback relevant to patellofemoral instability.

This prototype is not yet validated to detect or predict
patellofemoral instability.

## Initial milestones
- Read data from one IMU.
- Read timestamped data from two IMUs.
- Calibrate sensor placement.
- Estimate relative thigh and shank orientation.
- Log measurements for analysis.
- Test configurable feedback.

## Project structure
- firmware/: microcontroller code
- analysis/: data processing and visualization
- docs/: wiring, design notes, and testing procedures
- data/: local recordings, excluded from Git
